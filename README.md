# COD Partners — Clothing Ship on Demand

Modern React/Vite dashboard for clothing dropshipping and print-on-demand.

Included:
- Dashboard with order and production metrics
- Product catalog for pants, shorts, long sleeves, hoodies, gilets and bodywarmers
- Product search, filtering, sorting and favourites
- Custom neck label designer
- Custom packaging bag designer with front and back
- Custom hang tag designer
- Upload artwork, add text, choose colors and save branding presets locally
- Orders and fulfillment overview
- Responsive desktop/mobile layout

Run locally:

    npm install
    npm run dev

Production build:

    npm run build
